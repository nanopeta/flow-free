# Flow Free 開発引き継ぎ

添付の`flowfree.html`はAndroidブラウザで動作するフローフリーパズルゲームです。
これまでの開発を引き継いで、追加・修正の依頼に対応してください。

---

## ゲーム概要

同じ色の点を線でつなぎ、盤面の全マスを埋めるパズル。
単一HTMLファイルで完結（外部ライブラリ・サーバー不要）。

---

## レベル構成（9種）

| レベル名 | グリッド | 色数 | 問題数 |
|------|------|------|------|
| やさしい | 4×4 | 4色 | 5問 |
| ふつう | 5×5 | 5色 | 5問 |
| むずかしい | 6×6 | 5色 | 5問 |
| 上級 | 7×7 | 6色 | 5問 |
| エキスパート | 8×8 | 6色 | 5問 |
| マスター | 9×9 | 7色 | 10問 |
| レジェンド | 10×10 | 8色 | 10問 |
| エピック | 12×12 | 8色 | 10問 |
| ∞ モード | 選択式 | - | 無限生成 |

---

## 主要なデータ構造

```js
// ステージデータ
{ size: 9, pairs: [[r1,c1,r2,c2], ...], paths: [[[r,c],...], ...] }
// pairs = 各色の端点座標
// paths = 各色の正解経路（ヒント表示に使用）

// レベル定義
{ name: 'マスター', size: 9, stages: [...], infinite: true }
// infinite:true のものが∞モード
```

## 主要な状態変数

```js
let curLevel, curStageInLevel  // 現在位置
let N, pairs, paths, grid      // 盤面状態
let infiniteCount              // ∞モードのクリア数
let infFixedSize, infFixedNc   // ∞モードの選択サイズ・色数（0=ランダム）
```

## 主要な関数

| 関数 | 役割 |
|------|------|
| `buildLevelList()` | タイトル画面のレベル一覧を描画 |
| `showStageSheet(lvIdx)` | ステージ選択シートを表示 |
| `startLevel(lvIdx, stIdx)` | 指定レベル・ステージを開始 |
| `prepareStage()` | ステージを初期化・描画（∞モード対応） |
| `generateInfinite()` | ∞モード用問題をリアルタイム生成 |
| `regenerateAllStages()` | 全ステージを再生成 |
| `buildBoard()` | 盤面DOMを構築 |
| `renderCell(r, c)` | 1セルをSVGで描画 |
| `checkClear()` | クリア判定（∞モード分岐あり） |
| `showHintForColor(ci)` | ヒント表示（stage.pathsを直接参照） |

---

## 問題生成アルゴリズム

バックトラック付きランダムウォーク：
1. 開始点をランダム配置（隣接なし）
2. 各色のパスをランダムウォークで伸ばす
3. 詰まったら1〜4マス戻してやり直し
4. 全マス埋まったら端点を抽出して問題完成
5. 生成時のパスをそのまま`paths`に保存→ヒントに使用

解の保証：生成時にパスが確定しているため別途ソルバー不要。

---

## UI構成

- **タイトル画面**：レベル一覧 → タップでステージ選択シート → スタートポップアップ → ゲーム開始
- **ゲーム画面**：ヘッダー（タイトル/リセット/ヒント）、タイマー、盤面
- **クリア画面**：タイム・記録・もう一度/おわり/つぎへ/問題再作成ボタン
- **ヒント**：ヒントボタン→盤面の点がパルス→点をタップ→正解経路をハイライト

---

## 描画方式

各セルは`<div class="cell">`内にSVGを動的生成。
- 端点：`<circle>`
- パス：`<rect>`で中央から上下左右に伸ばす
- セルサイズは画面幅から動的計算

---

## 注意事項

- `content://`スキームではlocalStorageが使えない場合がある（memStoreでフォールバック済み）
- 再生成は同期処理（`setTimeout(..., 50)`でUI更新を先行）
- ヒントはstage.pathsを直接参照。フォールバック用にsolveForHint()もある
