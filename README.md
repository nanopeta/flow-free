# Flow Free

同じ色の点を線でつなぎ、盤面の全マスを埋めるパズルゲーム。
**単一の HTML ファイルで完結**し、外部ライブラリやサーバーを必要としません。
Android などのモバイルブラウザでの動作を想定しています。

## 遊び方

1. `flowfree.html` をブラウザで開く
2. レベルを選び、ステージを選択してスタート
3. 同じ色の 2 点を線でつなぐ
4. **すべてのマス**を線で埋めるとクリア

## レベル構成

| レベル名 | グリッド | 色数 | 問題数 |
|------|------|------|------|
| やさしい | 4×4 | 4色 | 5問 |
| ふつう | 5×5 | 5色 | 5問 |
| むずかしい | 6×6 | 5色 | 5問 |
| 上級 | 7×7 | 6色 | 5問 |
| エキスパート | 8×8 | 6色 | 5問 |
| マスター | 9×9 | 7色 | 10問 |
| レジェンド | 10×10 | 8色 | 10問 |
| エピック | 12×12 | 8色 | 10問 |
| ∞ モード | 選択式 | - | 無限生成 |

## 主な機能

- 9 レベル・全 55 問の固定ステージ＋∞モードの無限自動生成
- タイマーとベストタイム記録（localStorage、使用不可時はメモリへフォールバック）
- ヒント機能（正解経路をハイライト）
- 問題の再作成（バックトラック付きランダムウォークで解の保証された問題を生成）

## 開発

ビルド工程はありません。`flowfree.html` を直接編集してブラウザで開くだけで確認できます。

```sh
# ローカルで配信して確認する場合（任意）
python3 -m http.server 8000
# → http://localhost:8000/flowfree.html
```

設計の詳細・データ構造・主要関数の一覧は [`docs/HANDOFF.md`](docs/HANDOFF.md) と
[`CLAUDE.md`](CLAUDE.md) を参照してください。
